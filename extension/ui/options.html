Przy uruchomieniu przeglądarki

O tym, co otwiera się przy starcie, decyduje przeglądarka. Wklej ten adres w jej ustawieniach jako stronę startową — pokazuje kafelki zawsze, niezależnie od ustawienia nowej karty.
Gdzie to ustawić
  • Chrome, Brave: Ustawienia → Przy uruchomieniu → Otwórz konkretną stronę → Dodaj nową stronę.
  • Edge: Ustawienia → Start, strona główna i nowe karty → Po uruchomieniu Microsoft Edge → Otwórz te strony.
  • Opera: Ustawienia → Przy uruchomieniu → Otwórz określoną stronę lub zestaw stron.
  • Vivaldi: Ustawienia → Ogólne → Strona startowa → Konkretna strona.
  • Firefox: Ustawienia → Strona startowa → Strona startowa i nowe okna → Własne adresy.
